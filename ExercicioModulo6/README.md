
## controles

CAMERA:
- `W/A/S/D` : MOVIMENTA CAMERA
- MOUSE ROTACIONA
- `SHIFT` : DESCER CAMERA
- `ESPAÇO` : SOBE CAMERA 

OBJETO:
- `1/2/3` : ligar/desligar 1: luz principal, 2: luz preenchimento, 3: fundo
- `setas ←/↓/↑/→` : transladar o objeto no plano X/Z
- `I/J` : transladar o objeto no eixo Y
- `Z` : iniciar rotação contínua no eixo Z
- `X` : iniciar rotação contínua no eixo X
- `C` : iniciar rotação contínua no eixo Y
- `[` : aumentar escala uniforme
- `]` : diminuir escala uniforme
- `P` : adiciona ponto de trajetória
- `T` : ativar/desativar trajetória
- `O` : limpar ponto de trajetória
- `L` : salvar trajetórias
- `TAB` : troca objeto selecionado
- `ESC` : fecha a janela

## observações

- O codigo carrega modelos OBJ de `assets/Modelos3D/`
- é importante garantir que os arquivos OBJ existam neste diretório antes de executar o codigo
